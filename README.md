Syncro is a modern Android file sharing app built with Jetpack Compose. It blends a stunning space-themed UI with fast, secure local network transfers. Features include high-tech radar animations, offline discovery, and a sleek edge-to-edge design. Experience universal file sharing without the internet.

Right now it only works when both the parties are either connected to the same wifi network or when the receviver is connected to the sender's hotspot.
